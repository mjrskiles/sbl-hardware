# eda-lib

Shared KiCad libraries for SBL board designs.

- `symbols/` — schematic symbols
- `footprints/` — PCB footprints (`.pretty` directories)
- `3d/` — 3D models

Reference these via a `SBL_EDA_LIB` path variable in KiCad so projects
stay portable across machines.
